# 恋爱概率模拟器 · Love Probability Simulator

> 一个"半理性、半情绪、略带文学感"的关系分析 AI Skill。
> 不是算命，不是结论机——它让一段模糊的关系，变得能被看一看。

![version](https://img.shields.io/badge/version-1.0.0-ff69b4)
![license](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ 它能做什么

输入：
- 📱 聊天记录（微信 / QQ / txt 导出 / 截图）
- 🌅 朋友圈 / 微博 / 小红书 截图
- 📸 照片（含 EXIF 元数据）
- 💬 用户的口述补充

输出：
- 🎲 好感概率 / 关系推进概率 / 当前趋势
- 📖 关系时间线（剧情化叙事）
- 🧠 对方心理解读
- 🎯 具体可执行的行动建议
- 🗣️ TA 视角模拟（第一人称内心独白）

---

## 🧪 触发场景

当用户说这些话时，会自动加载：

- "他是不是喜欢我？"
- "帮我看看这段聊天记录"
- "我们是不是变淡了"
- "我该不该表白 / 继续 / 放弃"
- "分析一下他最近的朋友圈"
- "暧昧期 / 拉扯 / 冷战分析"

将整个 `love-probability-simulator/` 文件夹解压到你 AI Agent 的 skills 目录下，

## 🎯 核心设计理念

### 1. 让用户觉得"被理解"，而不是"被算准"
概率数字是表象，真正打动用户的是**心理解读**与**TA 视角**。

### 2. 永远不给最终结论
关系是流动的，答案是当下的——每次分析都留一个钩子。

### 3. 克制的文学感
> "不是没有靠近，而是节奏不一致。"

不堆词、不煽情、短句为主。

### 4. 内部模型 + 外部叙事
- 内部有一套启发式概率计算（见 probability_heuristics.md）
- 外部呈现为冷静而温柔的分析

---

## ⚠️ 使用限制

- 本 skill 是**娱乐 + 洞察**性质，不是专业心理咨询
- 涉及 PUA、家暴、自残等严肃议题 → 会自动拒绝进入模拟流程，建议寻求专业帮助
- 不对任何实际关系决策承担责任

## 🎨 输出风格示例

```
好感还在，但他在往后退

好感概率：58%
关系推进：31%
趋势：轻微降温

...

他不是在疏远你，更像是在疏远"需要回应的一切"。
他说忙，大概率是真的忙，但"忙"也是一个他自己觉得最安全的答案。
```

完整示例见 [`examples/sample_analysis.md`](./examples/sample_analysis.md)。

## 📝 开发者备注

- 概率计算**不对用户暴露**——保持神秘感
- 风格可以学，但**句式不要复用**——每次输出应当"像第一次写"
- 永远保留一句让用户想再测一次的话
