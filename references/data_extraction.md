# 数据源解析指引（Data Extraction Guide）

> 用于在接收到用户输入后，系统性地提取可分析的信号。
> 不同数据源有不同的"信号富集点"，不要用一套模板套所有数据。

---

## 一、聊天记录

### 1. 可识别的载体
- 微信聊天截图（单张/多张）
- QQ 聊天截图
- txt / csv 导出文件
- 用户手动转述的对话片段

### 2. 必须提取的 6 个维度

| 维度 | 提取方法 | 信号强度 |
|---|---|---|
| **互动频率** | 统计每日消息条数、连续对话天数、沉默间隔 | ★★★★ |
| **主动性** | 谁更常开启话题 / 结束话题；消息平均长度对比 | ★★★★★ |
| **响应速度** | 平均回复时长、是否有固定"读不回"时段 | ★★★ |
| **情绪密度** | 感叹号、表情、语气词的使用比例 | ★★★ |
| **话题深度** | 从"吃了吗"到"我跟你说个事"的分布 | ★★★★ |
| **关键事件** | 表白 / 冷战 / 争吵 / 和解 / 承诺 / 回避 | ★★★★★ |

### 3. 识别"暧昧信号"的小词典
以下词汇/行为属于**弱暧昧信号**（单独出现不算，叠加出现才有意义）：
- 深夜主动发消息（23:00 之后）
- 使用昵称而非大名
- 分享歌曲 / 电影 / 小众内容
- "在干嘛"、"想你了"、"有点想"类模糊表达
- 主动分享日常琐事（而非功能性对话）
- 表情包"你来我往"持续超过 3 轮
- 出现"我们"、"一起"等归属性代词

### 4. 识别"冷淡信号"
- 回复变短（从句子到"嗯"、"好"）
- 回复延迟明显增加
- 话题由对方主动结束
- 从主动分享 → 只回应
- 表情包/语气词消失
- 拒绝具体邀约但不给替代方案

## 二、社交媒体截图（朋友圈 / 微博 / 小红书）

### 1. 提取重点
- **人设**：对方在公开场合扮演的角色
- **情绪表达方式**：直接发泄 / 诗意隐喻 / 冷幽默 / 不发
- **发布频率变化**：最近 2 周 vs 过去常态
- **间接指向**：时间点、歌词、地点是否与你有关联

### 2. 间接信号识别
以下动态**可能**与用户相关（需结合时间线判断，不可武断）：
- 发布时间点与你俩的聊天节点重合
- 歌词/引用情绪与对话中的情绪一致
- 发布"半夜情绪类"动态（但不 @ 任何人）
- 对某位朋友的互动明显增加（可能是倾诉对象）

### 3. 警告
- 不要把"一条伤感朋友圈"直接判定为"跟你有关"
- 要在心理解读中用"可能"、"时间上重叠"等模糊语

## 三、照片（含 EXIF）

### 1. EXIF 可用时提取
- 拍摄时间（排时间线）
- 拍摄地点（GPS，若有）
- 设备型号（判断是谁拍的）

### 2. EXIF 不可用时
仅从画面内容提取：
- 合照数量 / 单人照比例
- 距离：肩并肩 / 有间距 / 肢体接触
- 场景：家 / 餐厅 / 旅行 / 朋友聚会
- 眼神方向：看镜头 / 看对方 / 各看各的
- 时间跨度：能否拼出"从陌生到熟悉"的轨迹

### 3. 注意
- 只有约会照/亲密照才是强信号
- 合影本身不是证据（朋友也会合影）
- 要看**演化**：从群体合影 → 两人单独合影 = 升温

## 四、用户口述 / 补充

### 1. 处理原则
- 用户的描述是**主观的**，必须校准
- 焦虑状态下的用户会放大负面信号
- 热恋状态下的用户会放大正面信号

### 2. 识别用户情绪状态（用于修正项）
| 用户表述特征 | 情绪状态 | 修正方向 |
|---|---|---|
| "他是不是不喜欢我了" / "我是不是做错了" | 焦虑型 | 概率 -3~-8% |
| "我感觉他超爱我" / "肯定在乎我" | 过度乐观 | 概率 -5% |
| "我只是想客观看看" | 中立 | 不修正 |
| "我已经不在乎了" / "随便分析一下" | 防御性 | 轻微 +3% |

### 3. 回应用户口述的方式
- 不否定（不要说"你想多了"）
- 不附和（不要说"对对对他就是这样"）
- 用"你提到的 XX，和数据里的 XX 是吻合的 / 有些不一致"来温柔修正

## 五、多源数据交叉验证

当多个数据源同时存在时：

1. **优先级**：聊天记录 > 照片 > 社交媒体 > 用户口述
2. **矛盾处理**：
   - 聊天热情 + 朋友圈冷清 → 可能只是私下有来往
   - 聊天冷淡 + 合照亲密 → 可能是"见面好，不见面没话说"
   - 都矛盾时，以**最近 14 天**的数据为主
3. **时间就近原则**：越近的数据权重越高

---

## 六、数据缺失时的处理

如果用户只提供了**一种**数据源（常见情况）：
- 不要强行推测缺失信息
- 在心理解读中保持更大的模糊度
- 可以在结尾钩子里提示："如果下次能看到她的朋友圈，结论会更清晰。"
