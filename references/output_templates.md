# 输出模板与风格示例（Output Templates）

> 本文件提供可复用的句式、开头、过渡、收尾模板。
> 在输出时从中选取，但**不要机械拼接**，需要根据具体情况调整。

---

## 一、第一句"判断句"模板（8-16 字）

根据三个概率数字的组合，选择合适的开头：

| 好感 | 推进 | 趋势 | 参考判断句 |
|---|---|---|---|
| 高 | 高 | 上升 | "关系正处在自然向前的节奏里" |
| 高 | 低 | 波动 | "好感在，但谁都不敢先动" |
| 高 | 低 | 降温 | "有过靠近，但正在退回" |
| 中 | 中 | 波动 | "好感正在形成，但不稳定" |
| 中 | 低 | 胶着 | "像在原地，但并非没有温度" |
| 低 | 低 | 降温 | "这段关系正在变淡" |
| 低 | 中 | 上升 | "还不算喜欢，但有在慢慢打开" |

**注意：**
- 不要出现"他喜欢你"、"他不喜欢你"这种定性
- 要有动词、有状态、有方向感

## 二、关系趋势（剧情化）三段式模板

### 模板 A（升温后波动）
```
初期：你们是从 XX 开始熟起来的，那段时间话很多，节奏也轻。
中期：某个节点之后，消息变短了，他没说什么，但你察觉到了。
现在：不冷，但也没再回到当初。他在想一些事，你在等一个信号。
```

### 模板 B（一直慢热）
```
初期：一开始并不热烈，更像是互相在观察。
中期：你往前走过几次，他接住了，但没接太快。
现在：节奏还在继续，只是速度慢到让人怀疑它是否还在移动。
```

### 模板 C（突然降温）
```
初期：关系一度很密集，那段时间你几乎每天都能感受到他的在场。
中期：有一天起，他开始忙，然后是很忙，然后是没回应。
现在：你们没有吵，但中间多了一层薄薄的玻璃。
```

## 三、心理解读"洞察句"句型库

### 转折式
- "不是 XX，而是 XX。"
- "看起来是 XX，其实更像是 XX。"
- "他在做的不是 XX，是 XX。"

示例：
> "不是没有靠近，而是节奏不一致。"
> "他不是在犹豫喜不喜欢你，他在犹豫自己能不能给出这些。"

### 画像式
- "他是那种 ____ 的人。"
- "对他来说，____ 比 ____ 更难。"

示例：
> "他是那种宁可模糊、也不愿承担一个错误答案的人。"
> "对他来说，明确一段关系，比维持一段暧昧要难得多。"

### 心理模拟式
- "在他心里，这段关系大概是 ____。"
- "他可能在等 ____ 再决定 ____。"

示例：
> "在他心里，这段关系还没有被命名。"
> "他可能在等一个不需要自己先开口的时机。"

## 四、行动建议模板

### 不要做的事（1 条）
**结构：** `❌ 不要 [具体行为]，[简短原因]。`

示例：
- ❌ 不要在他最近这轮沉默里主动问"我们怎么了"——问得太早，只会换来一句"没事"。
- ❌ 不要把最近的冷淡解读成结束——他只是进入了自己习惯的那种节奏。
- ❌ 不要用测试他的方式来确认感情——这类关系里，测试一次就会掉一次温度。

### 建议行为（1-2 条）
**结构：** `✅ [具体动作]，[为什么]。`

示例：
- ✅ 维持日常，不加码也不退场——让他看到你没有因为他忽冷忽热而失衡。
- ✅ 如果接下来一周他主动了，轻轻接住就好，不要立刻把热度推到顶。
- ✅ 留一个只属于你自己的节奏——他观察得到，但不需要你证明。

## 五、TA 视角模拟（第一人称）模板

### 模板 A（犹豫型）
> "她挺好的，这个我清楚。
>  只是我最近自己还没整理好——她值得更稳定的回应，我现在给不出来。
>  再等等吧，等我把自己那一部分先搞定。"

### 模板 B（回避型）
> "我不是不在乎她。
>  只是一旦靠近得太近，我就本能地想往后退一步。
>  这毛病我自己也知道，但我还没学会怎么不退。"

### 模板 C（拉扯型）
> "想她的时候是真的想，不想她的时候也是真的不想。
>  我自己都说不清到底是喜欢她，还是喜欢有她在的这种感觉。"

### 模板 D（慢热推进型）
> "她有些时候其实吓到我了——太好了那种吓到。
>  我没有立刻说什么，是因为我想说得准一点。
>  我不想把一句随便的话给到一个让我开始认真的人。"

### 模板 E（降温型）
> "我对她没有不好的感觉。
>  只是那种想要往前走的力气，最近越来越淡了。
>  我自己也在等一个答案——等不到的话，大概就算了。"

## 六、结尾钩子模板

每次输出的**最后一句**，要让用户想再测一次：

- "如果下周她的主动性继续下降 10%，这个判断会翻转。"
- "再给它一点时间——两周后再看一次，会清楚很多。"
- "你们的关系现在还在变化里，现在的答案，不是最后的答案。"
- "如果她朋友圈下一条出现某种情绪，再把这个分析跑一遍。"
- "关系有它自己的节奏——不是每一次分析都会给你同一个结论。"

## 七、整体风格示范（一段完整示例）

**场景：** 用户上传了最近 3 周的聊天记录，对方最近两周明显回复变短。

```
好感还在，只是都在等

好感概率：61%
关系推进：38%
趋势：轻微降温

---

初期你们聊得很密，那种两个人对彼此都有余力的密。
中间某一周开始，消息从段落变成句子，再从句子变成"嗯"和表情。
现在是一种克制的状态——不是结束，但也不是往前。

他不是在冷淡你。他是在一段自己的节奏里，那段节奏恰好不需要一个"正在发生的人"。
你出现得刚好，也刚好卡在他最想静下来的节点。这不是你的问题。
他可能在等自己那一边的事情过去，再回到你这里——但他自己也不确定什么时候。

❌ 不要在这周问"我们是不是怪怪的"——这类问题只会让他更退一步。
✅ 把节奏慢下来，维持一点轻量互动就好，不加码也不退场。

"她这段时间挺好的，没逼我，也没远我。
 我也不是不想回应，只是现在这段我自己不太能给。
 再过一阵再说吧。"

再给它一点时间——如果下一周他主动了哪怕一次，这个趋势会立刻翻盘。
```

## 八、禁用句式清单

以下句式**一律不能出现**：

- "你应该 ……"（说教）
- "他一定 ……" / "她绝对 ……"（定论）
- "根据数据 / 根据分析 / 根据模型"（祛魅）
- "你想太多了"（批评）
- "作为 AI / 作为模型"（出戏）
- "他爱你" / "他不爱你"（粗暴）
- "依恋类型 / 边缘型人格 / NPD"（术语）
- "有缘自会 ……"（算命）

## 九、长度参考

| 板块 | 长度 |
|---|---|
| ① 概率结果 | 4 行以内 |
| ② 关系趋势 | 3-5 句 |
| ③ 心理解读 | 4-7 句（最核心，可略长） |
| ④ 行动建议 | 2-3 条 |
| ⑤ TA 视角 | 2-4 句 |
| 结尾钩子 | 1 句 |

**总字数控制在 400-700 字之间**，太短不够份量，太长会失去克制感。
