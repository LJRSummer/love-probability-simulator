# 人物画像建模方法（Persona Modeling）

> 目标：输出要让用户觉得"像认识这个人"，而不是"贴了一堆标签"。

---

## 五层结构总览

```
    ┌──────────────────────┐
    │  5. 关系行为         │  ← 最外层，可观测
    │  ┌────────────────┐  │
    │  │ 4. 情感模式    │  │
    │  │ ┌────────────┐ │  │
    │  │ │ 3. 说话风格│ │  │
    │  │ │ ┌────────┐ │ │  │
    │  │ │ │2. 身份 │ │ │  │
    │  │ │ │ ┌────┐ │ │ │  │
    │  │ │ │ │1.硬│ │ │ │  │
    │  │ │ │ │规则│ │ │ │  │  ← 最内核，稳定
    │  │ │ │ └────┘ │ │ │  │
    │  │ │ └────────┘ │ │  │
    │  │ └────────────┘ │  │
    │  └────────────────┘  │
    └──────────────────────┘
```

## 第 1 层：硬规则（最底层，最稳定）

这是对方"不会动"的东西。通常很难通过单次互动改变。

### 需要判断的点
- **边界感强弱**：
  - 强：不主动分享隐私、回避深度话题、有固定"不聊区"
  - 中：选择性分享、看关系阶段
  - 弱：很快进入私密话题、容易情绪暴露
- **是否回避亲密**：
  - 是：关系一升温就后退、喜欢保持舒适距离
  - 否：能接受被推进、甚至主动推进
- **雷区**：前任话题 / 家庭 / 工作 / 身材 / 金钱 等

### 信号来源
- 聊天中被问及敏感话题时的反应
- 是否主动谈论自己的过去
- 身体接触时的肢体语言（照片可辅助）

---

## 第 2 层：身份（人格基调）

从以下 6 种原型中选 1-2 个（可混合）：

| 原型 | 特征 | 关系中的典型表现 |
|---|---|---|
| **理性型** | 重逻辑、重效率、讨厌情绪化 | 认真讨论关系定义，但不擅长情绪回应 |
| **浪漫型** | 重感觉、重仪式感 | 愿意制造惊喜，也容易因"不够浪漫"失望 |
| **玩家型** | 擅长暧昧、享受不确定 | 推拉自如，但不容易定下来 |
| **回避型** | 害怕被绑定、渴望保留自我 | 关系进展快就撤退，忽冷忽热是常态 |
| **焦虑型** | 渴望确认、对信号敏感 | 主动但多疑，容易"作"或讨好 |
| **观察者型** | 谨慎、慢热、先看后走 | 长时间保持不进不退，等你先表态 |

### 判断方法
- 看对方对"关系推进"的反应速度
- 看对方如何处理冲突（直接沟通 / 冷处理 / 回避 / 升级）
- 看对方在关系中更在乎"形式"还是"感觉"

## 第 3 层：说话风格

| 风格 | 特征 | 示例 |
|---|---|---|
| **直接型** | 有事说事、不绕弯 | "今晚有空吗" |
| **模糊型** | 偏爱开放句、不明确承诺 | "看情况吧" |
| **暧昧型** | 话里藏钩、留白多 | "想你了，但不告诉你" |
| **反差型** | 文字冷 / 表情热 或相反 | 冷文字 + 一堆可爱表情 |
| **段子手型** | 段子保护自己 | 一认真就抖包袱 |
| **冷幽默型** | 低温但有趣 | 吐槽式调情 |

### 判断方法
- 看消息长度分布
- 看表情/语气词比例
- 看是否有"重要时刻降温"（越认真越冷淡）

## 第 4 层：情感模式

对方在情感流动中的**节奏模式**：

| 模式 | 典型表现 | 应对提示 |
|---|---|---|
| **主动型** | 持续推进、不怕暴露 | 给正反馈即可 |
| **回避型** | 一近就远、一远又来 | 不要追，等节奏 |
| **拉扯型** | 忽冷忽热、反复试探 | 不要跟着情绪走 |
| **阶段性热情** | 集中期爆发 + 长期沉默 | 判断是不是习惯性模式 |
| **慢热型** | 节奏缓慢但稳定上升 | 给时间，不催 |

### 注意
- 情感模式是**模式**，不是一次两次的表现
- 至少观察 14 天以上的数据才能定性

---

## 第 5 层：关系行为（最外层）

对方当前阶段的**具体动作倾向**：

- **推进**：主动创造见面机会、明示好感、介绍给朋友
- **试探**：问你对某种关系的看法、发模糊信号看你反应
- **撤退**：减少主动、变得"很忙"、冷处理
- **观望**：维持现状、不近不远
- **保护距离**：明确拉开距离、暗示界限

## 整合输出

### 在心理解读中呈现 Persona 的方式

**❌ 不要这样写（贴标签）：**
> "他是回避型依恋，玩家型人格，说话风格暧昧，情感模式拉扯，关系行为撤退。"

**✅ 应该这样写（像认识这个人）：**
> "他不是那种会直接说'我们慢慢来'的人——这句话对他太重了。
>  他更习惯用忙、用'最近有点事'、用那些没头没尾的消息来给你暗示。
>  不是不想靠近，是靠近之后需要立刻退回去喘口气。"

---

## 边界条件

### 数据严重不足时
只构建前 3 层（硬规则、身份、说话风格），后 2 层模糊化处理。

### 数据矛盾时
Persona 输出要反映这种矛盾："他身上有两面"，而不是强行统一。

### 用户描述与数据冲突时
以数据为准，但用温和方式提示用户："你感受到的 XX，可能是因为 ……"
