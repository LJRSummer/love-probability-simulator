# 概率计算启发式规则（Probability Heuristics）

> 这是**内部启发式**，不要展示给用户。
> 目标不是算出"正确"的数字，而是算出"一个有说服力的数字"。

---

## 一、三个核心输出

| 指标 | 范围 | 含义 |
|---|---|---|
| **好感概率** | 0-100 | 对方对用户的整体好感程度 |
| **关系推进概率** | 0-100 | 近 2-4 周内关系向前一步的可能性 |
| **当前趋势** | 枚举 | 上升 / 轻微波动 / 波动 / 轻微降温 / 降温 / 胶着 |

---

## 二、基础分值分配

### 1. 主动性权重（30%）

| 主动性表现 | 分值 |
|---|---|
| 对方持续主动 70%+ 的对话 | 85-95 |
| 基本五五开 | 60-75 |
| 用户主动 60%+ | 40-55 |
| 用户主动 80%+ | 20-35 |
| 用户几乎单向输出 | 5-20 |

### 2. 互动频率（20%）

| 频率 | 分值 |
|---|---|
| 几乎每日有对话 | 85-95 |
| 隔日左右 | 70-82 |
| 每周 2-3 次 | 50-65 |
| 每周 1 次或更少 | 25-40 |
| 断续、有长期沉默 | 10-25 |

### 3. 最近关键事件（30%）

**正向事件（+）：**
- 表白或准表白 → +10~+20
- 主动见面 / 主动约 → +8~+15
- 分享私密话题 / 脆弱 → +6~+12
- 送礼物 / 记得小细节 → +5~+10
- 主动和解冲突 → +8~+15

**负向事件（-）：**
- 冷处理超过 3 天 → -8~-15
- 明确回避见面 → -10~-18
- 介绍自己的其他异性 → -5~-12
- 已读不回成为常态 → -6~-12
- 说"我们做朋友吧" → -15~-25

基础分从 50 开始加减。

### 4. Persona 匹配度（20%）

判断"对方的 Persona 与用户的需求"是否匹配：

| 匹配情况 | 分值 |
|---|---|
| Persona 高度兼容（都稳定推进型） | 80-95 |
| 基本兼容（一主动一慢热） | 60-75 |
| 节奏错位（焦虑 vs 回避） | 30-50 |
| 根本模式不同（玩家 vs 稳定型） | 15-30 |

---

## 三、加权合成

```
好感概率 = (主动性 × 0.3) + (频率 × 0.2) + (关键事件 × 0.3) + (Persona × 0.2)
```

然后：
```
关系推进概率 = 好感概率 × (0.5 ~ 0.8)
```
（推进概率**一般低于**好感概率，因为"喜欢"不等于"会推进"）

---

## 四、修正项

### 1. 随机波动（±5%）
每次输出时给两个概率各加一个 [-5, +5] 的随机偏移。
**为什么需要：** 避免机械感，让重复分析有微小变化。

### 2. 用户情绪修正

| 用户状态 | 修正 |
|---|---|
| 焦虑（反复问、担心被讨厌） | 好感 -3~-8%，推进 -5~-10% |
| 过度乐观（已经当恋人了） | 好感 -5%，推进 -8% |
| 冷静中立 | 无修正 |
| 防御性（"我不在乎了"但还在问） | +2~+5%（保留希望） |

**为什么要根据用户情绪修正：** 让结果贴近用户的"真实感受区间"，而不是冷冰冰的数字。

---

## 五、趋势判定

基于**最近 7 天 vs 之前 7 天**的变化：

| 变化 | 趋势标签 |
|---|---|
| 好感+互动都上升 | 上升 |
| 好感上升 / 互动下降 | 轻微波动 |
| 基本持平 | 胶着 |
| 互动下降 / 好感稳定 | 轻微降温 |
| 都下降 | 降温 |
| 大幅起伏反复 | 波动 |

---

## 六、极端值保护（避免输出离谱数字）

- 好感概率**不要低于 15%**（除非有明确拒绝），也**不要高于 90%**（保留余地）
- 推进概率**不要高于 80%**（即使极度乐观）
- 避免同时出现两个 85+ 的数字（会显得失控乐观）
- 避免同时出现两个 20- 的数字（会显得绝望）

---

## 七、特殊场景

### 1. 已经在一起但用户问"他/她还喜欢我吗"
- "好感概率"改为"在乎程度"
- "关系推进概率"改为"关系稳定度"
- 其他逻辑不变

### 2. 单向暗恋（对方基本无回应）
- 不要输出很低的好感（比如 8%）——这会让用户受伤
- 使用 28-42% 的区间 + "还没认识到你"之类的温和说法
- 趋势标记为"待开发"或"刚起步"

### 3. 复合可能性分析
- 需要额外一个指标"复合可能性"（替代推进概率）
- 趋势要基于"从分手到现在"而非"从认识到现在"

---

## 八、一致性检查（输出前自审）

在生成最终输出前，检查三件事：

1. ✅ 三个数字**内部逻辑一致**（好感高 → 推进不能太低）
2. ✅ 数字与**趋势**标签吻合（降温不能配高好感 85%）
3. ✅ 数字与**心理解读**吻合（数字显示 65% 但解读像 30% 不行）

如果不一致，优先调整数字，保持解读的深度和质感。
